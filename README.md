## 🌟 Key Features

- 🇲🇦 **24+ Verified High-Definition Live Streams**: Direct low-buffer streams for Morocco's favorite stations.
- 📊 **Animated Audio Equalizer**: Real-time visual equalizer reacting to playback states and audio output.
- 🗂️ **Smart Category Filtering**:
  - 🎵 **Music & Youth**: Hit Radio, NRJ Maroc, 100% Mgharba...
  - ⚽ **Sports & News**: Radio Mars, Medi1, Aswat, MFM Radio...
  - 🕌 **Quran & Cultural**: Quran Radio (إذاعة محمد السادس للقرآن الكريم), Med Radio, Chada FM...
- ⭐ **Favorites & History**: Save preferred stations to local storage for instant one-click access.
- 📱 **Mobile-First Glassmorphic Design**: Smooth transitions, backdrop-blur aesthetics, and full touch-screen optimization.
- ⚡ **Zero External Dependencies**: Pure vanilla JavaScript with zero bundle bloat and lightning-fast load times.

## 🛠️ Technology Stack

- **Frontend**: Vanilla ES6+ JavaScript, Semantic HTML5 Audio API.
- **Styling**: Tailwind CSS & Custom Glassmorphism CSS variables.
- **Icons**: FontAwesome 6 Pro & Heroicons.
- **Architecture**: Modular Client-Side Single Page Application (SPA).

## 🚀 Quick Run

No compilation or complex build step required! Simply run with any static web server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```
Then open `http://localhost:3000` in your web browser.
